# Paranın Yönü — grafik verileri
`market.json` Paranın Yönü’nde zaten yayımlanan günlük ve haftalık grafik serileridir. Şema sürümü 1: tarih, USD/TL, EUR/TL, gram altın (TL), BIST 100, BTC/TL, brüt mevduat birikimi, tahmini altın işareti, yıllık mevduat oranı ve tahmini oran işareti. Ham kaynaklar ve veritabanı ayrıdır.

Kaynaklar: [TCMB EVDS](https://evds3.tcmb.gov.tr/) / Borsa İstanbul ve [Coin Metrics Community](https://coinmetrics.io/community-network-data/) ([CC BY-NC 4.0](https://github.com/coinmetrics/data/blob/master/LICENSE)). Mevduat brüt birikim modelidir; BTC/TL referans değeri iki ayrı kaynağı kullanır.
